# Android Device Information Diagnostic Utility v1.1.0

A fastfetch-style command-line diagnostic tool specifically designed for Android terminal environments (Termux / ADB Shell).

---

## 🛠 Features in v1.1.0

- **Hardware & OS Info**: Device model, SoC platform, Android release, and SDK version.
- **Kernel Metrics**: Linux kernel release string, architecture, and SELinux enforcement status.
- **Dynamic System Metrics**: Live RAM utilization (MB), battery temperature monitoring (°C), and active CPU governor.
- **Network Metrics**: Active TCP congestion control algorithm (BBR/Cubic).

---

## 💻 Usage

```bash
./neofetch_android.sh
```
