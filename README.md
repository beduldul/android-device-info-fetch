# Android Device Information Diagnostic Utility

A fastfetch-style command-line diagnostic tool specifically designed for Android terminal environments (Termux / ADB Shell). Displays kernel versions, GKI ABI status, CPU governor, memory compression, and SELinux enforcement mode.

---

## 🛠 Information Displayed

- **Device Hardware**: Device model, SoC platform, and architecture.
- **Kernel & GKI Details**: Linux kernel version string, compiler toolchain, and GKI ABI status.
- **Subsystem Tunables**: Active CPU governor, TCP congestion control algorithm, and ZRAM status.

---

## 💻 Usage

```bash
./neofetch_android.sh
```
